# 经世智学 Demo 实施计划

日期：2026-09-12。用户已确认选题并授权发布至 lzh-ff/kedaxunfei。

## 设计

面向财经商贸专业群中的电子商务专业，核心岗位为电子商务运营专员。以“降价促销能否提高经营利润”为可完成的微任务，连接岗位能力、分步任务、参数实验、知识解释、测评与学习建议。

采用 GitHub Pages + 原生 JavaScript 模块。知识检索、确定性规则、数值计算、会话上下文均在浏览器运行。无服务器密钥、无外部模型请求；界面明确显示知识与规则生成，不声称已运行 MetaGPT 或微调模型。学习记录和试用反馈存于本机浏览器，可导出文件，不自动上传。

现有包用于继承“专业知识支撑 + 分层计算 + 可执行反馈”的设计；现有 MetaGPT 缺少可直接启动的经济学网页应用和生产配置。人岗匹配包缺少推理权重，因此不伪造模型匹配分数。论文的偏好函数以 α=β=0 的简化单阶段囚徒困境作教学实验，不声称复现实验训练效果。

界面采用简洁的浅色实训工作台：左侧导航、中央任务和实验、右侧导师与依据。手机端顺序折叠。信息图用于呈现真实计算结果。
