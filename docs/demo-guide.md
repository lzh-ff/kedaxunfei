# 职教自适应学习助手 · Demo 使用说明

公开链接：https://lzh-ff.github.io/kedaxunfei/

公开规则版无需账号、安装或模型密钥，支持电脑和手机。本机 SDK 版需要由运行者配置 DeepSeek 服务端密钥，页面不要求或保存密钥。专业场景：财经商贸专业群、电子商务（530701）、电子商务运营专员。

## 本机模型问答

按根目录 README 安装依赖并完成配置后，双击“启动本机DeepSeek问答.cmd”，打开 http://127.0.0.1:4174/kedaxunfei/ 。本机入口的“回答方式”可选“DeepSeek 在线”和“教材规则 · 离线”。点击发送前会说明本轮问题、有限近期对话与经营参数的发送范围；不要输入私人信息。

在线回答通过服务端的 OpenAI 官方 SDK 调用 DeepSeek，密钥留在本机服务端。等待时可取消；失败时页面显示错误，可以重试或点击“用教材规则回答此题”。每条回答显示生成方式；“本轮参考教材”是供人工核对的依据，不保证每句生成内容都正确。

此 SDK 版在本机运行，尚未发布到公开页面。打开页面不会自动上传已有对话，在线发送才会携带最多6条、合计最多4000字的近期对话。诊断、阅读、笔记和整份学习档案不随问答请求上传。

## 建议体验顺序（8—10 分钟）

1. 首页点击“开始诊断”，回答6道题；提交后查看学习路径和薄弱项。
2. 调整可用学习时间，观察当天安排。开始一节沉浸阅读，查看教材概念、原创岗位案例及来源。
3. 标记已读后，点击“复核与迁移练习”：1道基础题复核、2道新情境迁移题。提交后回到路径，观察证据与掌握度变化。
4. 首页输入“需求价格弹性”，继续问“举个例子”“依据是什么？”；输入“这个怎么弄？”体验澄清。历史对话可在侧栏或学习记忆中继续。
5. 岗位实训比较售价100元和80元，再把库存设为1100件，分别观察销量、收入和利润。选择不同业务情境与层级可生成新任务。
6. 写下经营判断，勾选自己完成的步骤，导出实训报告。扩展实验可调整合作概率与普遍化权重。
7. 学习空间及记忆展示实际阅读和作答；设置支持主题、时间及本机数据管理。
8. 实际体验后填写并导出反馈，主动交给参赛团队。网页不会自动上传。

## 如何理解学习进度

采用 DeepTutor 1.6.7 的近期加权正确率。1道不同题目的证据最高50%，2道最高80%；至少3道不同题、加权结果达到80%且最近答对，才标记本组达标。每题只取最新证据，阅读标记和重复同题不会增加题目数。

安排先看薄弱项，再照顾未掌握的先修内容，并控制在可用时间内。初诊错题可在对应能力内复核，不必重做整个诊断。本组结果不是完整岗位能力认证。

## 当前公开版范围

界面与架构参考 DeepTutor，按比赛场景裁剪。问答来自浏览器教材知识和规则，没有在线大模型、完整代理运行时、任意文件检索或多用户服务。Python 算法服务随源码交付，公开页面不依赖它。

经营数字均为教学模拟，计算公式可查看，不作为实际经营预测。知识来源为 OpenStax、MIT OCW、教育部教学标准；未导入商业平台的受限题库。

数据保存在当前浏览器，不跨设备自动同步。清除浏览器数据会丢失记录，请先主动导出。兼容迁入原经世智学的笔记、参数及已提交诊断证据。

此 Demo 不代表已完成真实师生试用或正式提交，其他参赛材料和演示视频另行核查。
