# 02-作品Demo：经世智学使用说明

作品：经世智学 · 电子商务运营岗位实训。

目标链接：https://lzh-ff.github.io/kedaxunfei/ 。上线状态见同目录 `deployment.md`。

无需账号、API密钥、附件上传或软件安装。用支持JavaScript的现代浏览器打开链接即可体验。知识与计算在浏览器运行，首次需加载页面文件。

## 适用对象和任务

对象为财经商贸专业群中电子商务专业学生及任课教师；典型就业岗位是电子商务运营专员。核心任务是比较促销方案，区分销量、收入、利润与库存约束。此痛点来自公开标准和教材的教学设计，当前未取得一线教师访谈佐证。

覆盖比赛方向：岗位能力图谱、典型工作任务转化成学习型任务、个性化自适应学习。

## 建议体验路径

1. **实训工作台**：选择“促销定价 / 基础 / 30分钟”，生成任务。
2. 将售价设置为100元：基准销量1000件、单位变动成本60元、固定成本10000元时，利润为30000元。
3. 将售价调为80元、弹性保持1.5。观察需求增加，但利润降低。把库存设置为1100件后，销量上限1100件，收入88000元，利润12000元。
4. 向导师提问“这个怎么弄？”，查看澄清提示。再输入“需求价格弹性”，依次追问“举个例子”“依据是什么？”；点击出处打开原始教材章节。
5. 打开**岗位能力图谱**，查看六个能力单元和关联知识。它是教学图谱，不是模型预测的岗位匹配分数。
6. 打开**学习诊断**，完成6题。系统按答案显示复习维度和学习资源。每维度仅1题，正确率不是全面的岗位能力鉴定。
7. 打开**偏好实验**，保持对手合作概率0.5。κ=0时背叛效用3、高于合作1.5；κ=0.5时合作效用2.25、高于背叛2。改变参数观察边界。
8. 回到工作台，填写自己的判断、勾选实际完成步骤，点击**导出实训报告**。报告记录当前输入、计算、测评、来源与学习笔记。

## 反馈与隐私

点击右上角“试用反馈”，由实际使用者选择学生/教师身份，填写专业或任教学科、三项评分、有帮助之处和改进建议，并确认本人真实试用。点击“导出反馈记录”，得到本地JSON文件。它不会自动上传或发给团队，需自行交给参赛团队汇总。

不输入姓名、手机号、学生名册、真实订单或顾客信息。学习进度仅存于浏览器本地，可从体验说明页清除。对话仅保留在当前打开的页面内，刷新会清空。

## 实际实现与未实现能力

页面显式标注“AI生成内容：知识与规则生成”，没有外部模型调用；自然语言支持由关键词检索与上下文规则实现，复杂或不相关问题可能需要重述。

65条知识有章节来源；定价为恒定弹性与固定单位成本下的教学计算；偏好实验为论文函数的单阶段简化。没有执行论文中的微调，也没有声称论文实验结果属于本团队。

本使用说明和体验链接构成Demo材料。参赛要求的其他文件及真实2—3名目标师生反馈需另行整理，不能用助手自测代替。
